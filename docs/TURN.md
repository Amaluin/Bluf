# TURN: видео и микрофон на смартфонах

На смартфоне в лобби и в игре часто **не видно и не слышно оппонентов**, хотя с компьютера в браузере всё работает. Причина — мобильный интернет (4G/5G) и многие Wi‑Fi используют **симметричный NAT**: прямого P2P по одному STUN недостаточно, нужен **TURN**‑сервер, который ретранслирует медиа.

---

## Пароль: не ищут, а придумывают

**Пароль нигде не «находится»** — его нужно **придумать самому**, как пароль от нового аккаунта. Один и тот же пароль вы потом пропишете в двух местах: в конфиге coturn на сервере и в `config.js` в проекте Bluf.

Пример: придумали пароль `moyaTURNsecret`. Он будет в конфиге coturn в строке `user=bluf:moyaTURNsecret` и в config.js в поле `credential: 'moyaTURNsecret'`.

---

## 1. Установка coturn (на сервере по SSH)

Подключаетесь к серверу (где крутится Bluf) по SSH и выполняете:

```bash
sudo apt update
sudo apt install -y coturn
```

Включить сервис:

```bash
sudo sed -i 's/#TURNSERVER_ENABLED=1/TURNSERVER_ENABLED=1/' /etc/default/coturn
```

(Если команда не сработает — откройте `sudo nano /etc/default/coturn` и вручную измените строку на `TURNSERVER_ENABLED=1`.)

---

## 2. Куда вписать настройки (INI)

Настройки coturn лежат **в одном файле на сервере**. Вы его создаёте или правите.

**Шаг 1.** На том же сервере откройте файл конфига:

```bash
sudo nano /etc/turnserver.conf
```

Если файла нет — он создастся при сохранении.

**Шаг 2.** Вставьте в файл **целиком** такие строки (замените только два значения):

- **Вместо `2.56.241.41`** — IP вашего сервера (тот же, по которому заходите в Bluf в браузере).
- **Вместо `moyaTURNsecret`** — любой придуманный вами пароль (латиница/цифры, без пробелов).

```ini
listening-port=3478
tls-listening-port=5349
external-ip=2.56.241.41
realm=bluf
server-name=bluf
lt-cred-mech
user=bluf:moyaTURNsecret
no-multicast-peers
no-cli
```

**Шаг 3.** Сохранить и выйти: в nano это `Ctrl+O`, Enter, затем `Ctrl+X`.

**Шаг 4.** Запустить coturn:

```bash
sudo systemctl enable coturn
sudo systemctl restart coturn
```

Итого: INI-настройки — это **содержимое файла `/etc/turnserver.conf` на сервере**. Пароль вы придумываете и один раз пишете в строке `user=bluf:ваш_пароль`.

## 3. Фаервол

Откройте порты для TURN:

```bash
sudo ufw allow 3478/udp
sudo ufw allow 3478/tcp
# диапазон для реле (по умолчанию coturn использует 49152–65535)
sudo ufw allow 49152:65535/udp
sudo ufw reload
```

## 4. Конфиг в проекте Bluf (config.js)

В **вашем проекте Bluf** откройте файл **`public/config.js`** (на компе в редакторе или на сервере в `~/Bluf/public/config.js`).

Добавьте или измените блок `BLUF_TURN` так, чтобы:

- **url** — был тот же IP (или домен), что и у Bluf, и порт `3478`.
- **username** — всегда `bluf` (как в конфиге coturn).
- **credential** — **тот же пароль**, что вы придумали и вписали в `/etc/turnserver.conf` в строку `user=bluf:пароль`.

Пример (IP и пароль как в примере выше):

```js
window.BLUF_TURN = {
  url: 'turn:2.56.241.41:3478',
  username: 'bluf',
  credential: 'moyaTURNsecret'
};
```

То есть пароль в `credential` и пароль после двоеточия в `user=bluf:...` в INI — **один и тот же**.

## 5. Проверка

Перезалейте обновлённый `config.js` на сервер, обновите страницу на смартфоне (лучше с полной перезагрузкой). Зайдите в лобби, включите камеру/микрофон. После настройки TURN оппоненты должны быть видны и слышны и с телефона.

В браузере (F12 → Console) можно посмотреть, используется ли TURN: в логах ICE или в `pc.iceConnectionState` после установки соединения.

---

## Кратко

| Где            | Что |
|----------------|-----|
| Сервер         | Установить coturn, настроить `external-ip`, `user=bluf:пароль`, открыть порты 3478 и 49152:65535/udp |
| `public/config.js` | Задать `window.BLUF_TURN = { url: 'turn:IP:3478', username: 'bluf', credential: 'пароль' }` |

После этого видео и микрофон должны работать и в лобби, и в игре, в том числе на смартфонах.
