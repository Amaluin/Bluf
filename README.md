# Верю / Не верю (Bluf)

Карточная игра для 2–6 игроков по сети. Веб-приложение с адаптивным интерфейсом под мобильные устройства.

## Правила

- Колода: 52 карты (без джокеров). В начале игры карты раздаются поровну; если 52 не делится на число игроков, остаток случайно достаётся нескольким игрокам.
- Перед началом игры каждый игрок бросает кубик. Игрок с наибольшим результатом ходит первым, остальные по часовой стрелке.
- Каждый игрок видит только свои карты.
- Игроки ходят по очереди. Можно:
  - **Положить карты** (1–4) рубашкой вверх и **заявить ранг** (например, «две пятёрки»). Можно блефовать — заявленный ранг может не совпадать с картами.
  - **Верю** — передать ход следующему. Если заявление было правдивым, карты уходят в отбой.
  - **Не верю** — вскрыть последнюю положенную группу карт. Если заявление было ложным, все карты со стола забирает тот, кто положил, и ход переходит к тому, кто раскрыл обман. Если правдивым — забирает вызвавший «Не верю», а ход переходит дальше.
- Цель — первым избавиться от всех карт.

## Запуск

```bash
npm install
npm start
```

Сервер запустится на `http://localhost:3000`. Для разработки с автоперезагрузкой:

```bash
npm run dev
```

## Сетевая игра

1. Один игрок нажимает **«Создать игру»** и получает код комнаты (6 символов).
2. Остальные вводят этот код и нажимают **«Войти»**.
3. Когда в комнате 2–6 игроков, создатель нажимает **«Начать игру»**.
4. Игроки бросают кубик для определения порядка хода.
5. Для игры с одного устройства можно открыть несколько вкладок или использовать несколько устройств в одной сети (подключение по IP: `http://<IP>:3000`).

## Сборка APK (Android)

Можно собрать Android-приложение: тот же интерфейс, подключение к вашему серверу. Подробно — **[BUILD_APK.md](BUILD_APK.md)**.

Кратко: задать адрес сервера в `public/config.js`, выполнить `npx cap sync`, открыть папку `android` в Android Studio и собрать APK (Build → Build APK(s)).

## Стек

- **Сервер:** Node.js, Express, Socket.IO (комнаты, состояние игры).
- **Клиент:** HTML, CSS, JavaScript; адаптивная вёрстка, мобильный первый подход.
- **Android:** Capacitor (обёртка веб-приложения в APK).
